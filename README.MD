# Monitoramento de Memória RAM

Projeto desenvolvido em Python para monitorar o uso da memória RAM do computador.

## Objetivo

Realizar a coleta e exibição das informações de utilização da memória RAM,
servindo como uma das etapas do agente de monitoramento do projeto de
Sistemas Distribuídos.

## Funcionalidades

- Exibe a memória RAM total.
- Exibe a memória RAM utilizada.
- Exibe a memória RAM disponível.
- Exibe o percentual de utilização da RAM.
- Atualiza as informações a cada 5 segundos.
- Gera alerta quando o uso da memória está elevado.
- Gera alerta crítico quando o uso da memória está muito alto.

## Tecnologias utilizadas

- Python
- Psutil
